term: "Unit Test"

This type of testing focuses on the smallest testable parts of an application, often individual functions, procedures, or methods. The goal is to determine if each unit of the software performs as expected. Developers write these tests to ensure that each piece of code works correctly before it is integrated into larger parts of the program. This proactive approach helps catch bugs early in the development cycle, making them easier and less expensive to fix.

For instance, a developer might write a unit test to confirm that a function designed to calculate sales tax returns the correct amount for various input values.

Unit tests are a fundamental practice in software development, particularly in agile methodologies and during the implementation phase of coding.
