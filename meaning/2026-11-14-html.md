HTML is a system of organizing and presenting content on the World Wide Web. It uses special codes, called tags, to mark up text and images, telling web browsers how to display them. For example, a tag like `<p>` indicates the start of a paragraph, and `<img>` is used to insert an image.

A simple webpage might begin with a title enclosed in `<h1>` tags:
`<h1>My First Webpage</h1>`

This language is the foundation of virtually all content viewed through a web browser.
